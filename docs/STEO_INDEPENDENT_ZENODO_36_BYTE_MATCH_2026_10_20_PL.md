**Real public evidence run:** [GitHub Actions #39444963696](https://github.com/gniewkob/Investment-Strategy-Lab/actions/runs/39444963696), status **SUCCESS**. Implemented via [PR #51](https://github.com/gniewkob/Investment-Strategy-Lab/pull/51). This is independently sourced REAL source content, not synthetic test values.

**Independent source:** Catalyst Cooperative, [EIA STEO Zenodo version 2.0.0, DOI 10.5281/zenodo.15386905](https://zenodo.org/records/15386905), **published May 26, 2025**. Public yearly original source ZIP partitions `eiasteo-2022.zip`, `eiasteo-2023.zip`, `eiasteo-2024.zip`, with each ZIP original MD5 matching the independent Zenodo manifest, were downloaded and checked on Oct 20, 2026. All original EIA XLSX members in those 3 years were re-read and checked against our earlier, independently collected original EIA October-2026 source hashes documented in [2022–2023 source receipts](STEO_REAL_2022_2023_FROZEN_HISTORY_2026_10_20_PL.md) and [2024–2026 source receipts](STEO_FULL_34_REAL_RESULTS_2026_10_20_PL.md).

**Result: EXACT ORIGINAL XLSX BYTE MATCH 36/36, DIFFERENCES 0.** Original XLSX bytes are identical *between the independent third-party deposit published May 26 2025 and original XLSX files served by EIA and obtained October 20 2026*, as proven by matching SHA-256 of every original file. ZIP MD5 is only integrity-checking against the publisher's own declared zip checksum; individual SHA-256 comparisons are the original byte equality evidence. No source file changed in-between these two externally observed timepoints in a way that produced different bytes at those two points; this does NOT prove the files were continuously unchanged at every intervening time.

## What is established, what is not

**Established:** independent repository published May 2025 has the same genuine source bytes as current original EIA XLSX for all 36 issue-month files from Jan2022–Dec2024. This is independent third-party data provenance for those exact original files, stronger than an EIA 2026 re-download and unrelated to merely agreeing WTI/Brent monthly quote cells.

**NOT established:** that the file bytes were exactly as published on their original 2022, 2023 or 2024 release dates. A monthly source might have been revised in a period between initial release and third-party 2025 deposit. Official notices already establish some STEO report corrections, though none directly proves a WTI/Brent Table2 change. This 2025 deposit cannot retroactively certify those original day-specific bytes.
